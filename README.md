# Habit Tracker
I will attempt at re-creating the github commit tracker in a CLI.

why you ask? Great question, the only thing that motivates me to program is a litte square box and the number 
of days I have programmed in a row (my streak on bootdev). I will try to recreate this rat behaviour for 
other aspects of my life therefore the little square boxes will need more features.

1. track user habit and activities
2. show a little github like graphic to visualise your streak
3. Also show a streak somewhere
4. (optional) have a reminder system to bully the user into doing their habit.
5. (optinal) made digital notes with a completed activity as a sort of diary.
